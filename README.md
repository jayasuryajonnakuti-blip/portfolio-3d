## ⚡ Tech Stack & Performance Budget

- **Core:** React 19.2.0, TypeScript 5.7, Vite 6.2, React Router 7
- **3D & Graphics:** Three.js, `@react-three/fiber` v9, `@react-three/drei`
- **Motion & Physics:** GSAP ScrollTrigger, Lenis smooth scroll
- **Performance Budget:** Adaptive particle count (300 particles on mobile/low-end CPUs, 900 on desktop)
- **Accessibility:** High contrast (WCAG AA), keyboard navigable, `prefers-reduced-motion` compliance

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/jayasuryajonnakuti-blip/portfolio-3d.git
cd portfolio-3d

# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Run TypeScript compilation and production build
npm run build

# Preview production build locally
npm run preview
```
